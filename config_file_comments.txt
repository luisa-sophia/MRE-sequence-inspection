"SCANNERS":                                one block per scanner, the key (e.g. "7T") is used as label and in output file names.
                                           To add a scanner, add another block with the same three entries:
    "RELATIVE_DICOM_ROOT":                 the top root directory to the dicom files of this scanner, without the drive directory
    "RELATIVE_OUTPUT_DIR_ROOT":            the output top root directory for this scanner, without the drive directory
    "FOLDER_TEMPLATE":                     the folder template to the dicom files, MUST have {dicom_root} and {subject} placeholders

"DICOMINFO_TSV_NAME":                      name of the dicom tsv after modifying contents. MUST have {subject} placeholder
"METADATA_SUMMARY_TSV_NAME":               name of the MRE metadata summary per scanner. MUST have {scanner} placeholder
"MODALITY_SEQUENCE_IDENTIFIER_PATTERNS":   rules by which a scan is recognized as a certain modality (e.g. given series description xy, is it a t1w scan?).
                                           regex patterns, case insensitive, matched anywhere in the series description (re.search).
                                           A modality matches if any of its patterns match; a scan can count for several modalities.
